# 北纬秋行 · 动态路线

2026 年 9 月 27 日至 10 月 3 日大兴安岭自驾旅行路线原型。路线、取还车位置、酒店和天气仍需出发前核对。

## 本地预览

```sh
npm install
npm run dev -- --host 127.0.0.1 --port 4173
```

## 验证与静态构建

```sh
npx tsc --noEmit
node scripts/check-data.mjs
node scripts/check-literary.mjs
node scripts/check-day-visuals.mjs
node scripts/check-road-experience.mjs
node scripts/check-driving-effort.mjs
node scripts/check-forest-and-loading.mjs
node scripts/check-map-delivery.mjs
node scripts/check-regional-foliage.mjs
npm run build
```

静态产物位于 `dist/client`。地图默认显示 OpenStreetMap 完整道路与地名，启用 Leaflet 高分屏瓦片适配并移除淡化滤镜；连续拖动结束后再加载瓦片。约 6 KB 的 Natural Earth 河湖简图仅作备用背景，可主动切换；简图没有完整道路和行政边界，不替代导航。网络慢或失败仍有明确反馈；高分屏清晰度需要更多瓦片请求，不声称同时降低地图流量。路线为百度地图查询快照，展示前由 BD09 转换至 WGS84。外部导航使用原始 BD09 坐标。每天的路线、小车播放、进度条、机场／长春西站和松原住宿方案可以联动切换。

地域植物不再只是同一白桦叶换色：杨叶用于平原与长春，白桦用于林草过渡与额尔古纳，草原细草用于海拉尔、满洲里与新巴尔虎，落叶松针簇用于伊尔施、阿尔山。日期轴按当日道路景观选材，途经站点按地点区分；地图美景叶标、移动日期栏及点击/滚动短动效一并联动。四类图形为原创意象，不是城市独有植物、植物鉴定图或今年物候保证。

超宽屏主画布限制为 1480 CSS px，居中留白；图片与地图跟随画布，不横向铺满大显示器。地图导航颜色独立于秋季装饰：白色外沿、深蓝描边、蓝色规划线、灰色已回放轨迹；美景金色虚线位于主路线下方。颜色不表示实时畅通或拥堵。底图切换与美景开关并列，避免重叠。

叶片仅响应滚动或点击，自动消失，静止时不循环播放。可通过“秋意”关闭，并遵循系统减少动态效果偏好。

地图前的七天行程采用白桦枝干与叶片时间轴；地图后是无卡片框的“路上，读到北方”文化长卷，以河流、草原、远方、归途串起五组文学、影视及摄影作品。文字与影像通过留白、柔和遮罩和层次交叠融合，滚动进入时短暂显现，不循环播放。作品资料在 `app/cultural-works.json`；地点关系分为真实访问地、取景城市、叙事目的地和区域延伸阅读。

仅保留《额尔古纳河右岸》的一段短引，其余串联文字是原创旁白。小说氛围图、历史城市照片分别标注，不相互冒充；王伟摄影系列没有复制原图，只链接清华美院原作与收藏记录。《大象席地而坐》使用 Rediance 官方的夜色山峦、远处旅人与客车剧照，39 KB 本地低分辨率配图融入黑场，并注明不是满洲里实景。电影与央视视频按钮打开对应官方入口，不自动播放，访问和观看条件以来源平台为准。阅读按钮只切换既有日程，不增加根河、陈旗旧址或影视打卡绕行；10月3日仍仅安排还车。

首次打开默认 D1。标题新增本地 Ma Shan Zheng 毛笔楷书字集（SIL OFL 1.1，约 37 KB），正文与控制保持系统字体。原始生成 PNG 保留，页面使用轻量 WebP；地图图标/弹窗直接构建 DOM，不再把服务端 React 渲染器打包到浏览器。

地图与文化长卷之间新增“把秋天，开成一部电影”静态秋林背景。按用户最新反馈，已去掉小车图层、播放条与全部穿行逻辑，只保留图片和文字构图。图片使用响应式 WebP 与原生延迟加载，不是真实道路复刻。地图内的路线回放功能保持不变。

每天独立的头图和来源记录保存在 `app/day-scenes.json`；叶片地域色板位于 `app/season-palette.ts`。七天各用一张不同的历史照片，夏季图片明确标注。配色只是地域与景观的季节氛围示意，不代表 2026 年入秋程度的实测或预报。切换取还车点、松原住宿选项不改变 D6 从阿尔山市区出发的照片含义。

沿途美景数据在 `app/road-scenes.json`，位置解析在 `app/road-experience.ts`。地图与下方当日美景列表联动；金叶及短线只示意景观路段，不提供停车导航，P 标才对应已核验的停车入口。入口开放及停车规则尚待出发前核对。全部标记沿用现有路线；D6 会随机场／西站／松原方案匹配实际轨迹，不增加观景绕行。

`DrivingEffort` 按单人、白天正常路况区分“AD Pro 操作减负”和“全天驾驶／体力负担”，随日期及松原方案变化。它是定性行程判断，不是疲劳实测或车辆已开通能力的保证；未用百分比、减少休息次数或等效驾驶小时夸大辅助驾驶收益。D6 直返保持全程最高负担提示。展开可查官方依据与取车核对清单。

素材来源及生成提示词见 [ASSETS.md](ASSETS.md)，验证记录及范围限制见 [VALIDATION.md](VALIDATION.md)。不要在此项目中保存地图 MCP 或 JavaScript API 密钥。

## 2026-09-10 加载与发布修复

- 原先两处线上页面均为旧版本，仍默认 D4、引用约 2.43 MB 的 Wikimedia 原图与较大的 PNG。D4 现用 42,922 字节 WebP，保留署名、来源与 CC BY-SA 3.0；其它新闻照片保留来源链接及失败回退，不绕过防盗链。
- `routes.generated.json` 原始轨迹未改。构建前将坐标无损差分编码到 `routes.compact.json`，551,410 → 134,288 字节；每条轨迹逐点、所有导航元数据都做一致性断言。构建运行于 Node 22.13+。
- GitHub Pages 的独立发布副本须执行 `node scripts/prepare-github-pages.mjs /absolute/output` 和 `node scripts/check-github-pages.mjs /absolute/output`。修复了反引号字符串、内嵌 RSC 字体路径及重复前缀；不要把 Pages 专用前缀写入 Sites 的原始构建目录。
- `scripts/probe-delivery.mjs` 仅做少量 HTTP 采样，不代表浏览器 LCP 或所有地区的连接质量。海外站点和详细瓦片仍受访问网络影响。若要更稳定的国内详细地图，需要合规的国内浏览器地图服务及域名授权；百度 MCP 不是浏览器 SDK 的 AK。
